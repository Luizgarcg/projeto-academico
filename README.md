🎮 GameNews

Um site de notícias sobre jogos desenvolvido como projeto acadêmico para praticar desenvolvimento web utilizando HTML e CSS.

📖 Sobre o projeto

O GameNews é um portal de notícias voltado para o universo dos games. Atualmente, o projeto está em fase inicial de desenvolvimento e conta com uma tela de login, que servirá como porta de entrada para as próximas funcionalidades do sistema.

O objetivo é evoluir o projeto até se tornar um portal completo com notícias, lançamentos, análises e conteúdo sobre jogos.

🚧 Status do projeto

Em desenvolvimento 🚀

Funcionalidades atuais

* ✅ Tela de login.
* ✅ Interface moderna.
* ✅ Layout responsivo.

Funcionalidades planejadas
